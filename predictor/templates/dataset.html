Dataset Insights

Temporal Analysis

Records span thirteen consecutive years, enabling the LSTM branch to learn temporal dependencies and year-over-year patterns in crime occurrence.

Spatial Analysis

District-level records across states and union territories provide the spatial information required to model regional crime patterns.

33 Features

Thirty-three engineered features are available for the Hybrid CNN-LSTM-GCN model input pipeline.

Preprocessing

The dataset is prepared and formatted through the existing project data pipeline before being supplied to the prediction system.

Dataset Information

Source

The dataset contains historical district-level crime records aggregated into a structured dataset used by the Hybrid CNN-LSTM-GCN crime prediction system.

Collection Period

The available dataset covers annual reporting years from 2001 to 2013.

Feature Pipeline

The feature-engineered dataset contains the structured inputs used by the project's prediction pipeline.

Dataset Structure

Records are organized by state, district and year, together with crime indicators and engineered numerical features.

Data Integrity

Dataset records are loaded through the project's DatasetLoader and validated against the expected dataframe structure before being used by the application.

Model Usage

The engineered dataset provides the spatial and temporal information required by the Hybrid CNN-LSTM-GCN prediction framework.

Research Methodology

Tri-Modal Hybrid CNN-LSTM-GCN Framework for Spatio-Temporal Crime Prediction

The methodology unites spatial learning through a 1D Convolutional Neural Network (CNN), temporal dynamics through a Long Short-Term Memory (LSTM) network, and topological neighborhood diffusion via Spectral Graph Convolutions (GCN).

Dataset & Geographic Graph Ingestion

Longitudinal District Records & Node Centroids

The framework is trained on 9,385 longitudinal district-level crime records spanning 2001–2014 across 36 Indian States and Union Territories. Each district record is mapped to authoritative geographic latitude/longitude centroid coordinates to establish the underlying $850 imes 850$ spatial topological graph.

Source: Crimes in India Dataset (National Crime Records Bureau / Kaggle)

Data Preprocessing Pipeline

Raw statutory crime records are cleaned, normalized, and transformed into multi-dimensional tensors prior to parallel branch ingestion.

Data Cleaning & Alignment

Reconciling administrative boundary shifts, state reorganizations, and formatting variations.

Missing Value Imputation

Imputing missing historical entries using localized regional spatial medians and trend interpolation.

Standard Normalization

Feature-wise z-score scaling ($z = (x - \mu)/\sigma$) preserving relative variance for stable gradient descent.

3-Year Sliding Windows

Constructing sequential tensors $(X_{t-2}, X_{t-1}, X_t)$ for temporal memory ingestion by the LSTM branch.

Feature & Graph Topology Engineering

33 Model-Ready Features & 850×850 Adjacency Graph

The research framework prepares 33 model-ready spatial and temporal features from the preprocessed crime dataset. These engineered features give the 1D-CNN (spatial branch) and LSTM (temporal branch) structured signals to extract localized crime density and multi-year momentum.

Concurrently, the Spectral GCN branch consumes the static $850 imes 850$ spatial adjacency matrix ($ ilde{A}$) computed from geographic centroid coordinates via a Gaussian kernel ($A_{ij} = \exp(-d_{ij}^2 / 2\sigma^2)$ for $k=5$ nearest neighbors). This separates topological graph diffusion from 1D tabular convolutions.

Three Parallel Architectural Branches

Each branch independently processes a dedicated dimensional modality before joint latent fusion.

Branch 01

1D-CNN — Spatial Learning

Extracts localized spatial correlations and inter-category relationships across 33 statutory crime dimensions.

  • Input Tensor: Shape (Batch, 1, 33)
  • Layers: Conv1D (64 filters, $k=3$, ReLU) → MaxPool1D → Dropout(0.2)
  • Output: 64-dimensional spatial embedding
Standalone $R^2 = 91.41\%$ · RMSE = 891.70
Branch 02

LSTM — Temporal Learning

Models sequential momentum and longitudinal trend dynamics across 3-year sliding historical windows.

  • Input Tensor: Shape (Batch, 3, 33)
  • Layers: LSTM (64 units, return seq) → Dropout(0.2) → LSTM (32 units)
  • Output: 32-dimensional temporal hidden state
Standalone $R^2 = 81.34\%$ · RMSE = 1,529.02
Branch 03

Spectral GCN — Topological Learning

Propagates spatial crime influence across neighboring districts via normalized graph Laplacian convolutions.

  • Input Graph: $850 imes 850$ Normalized Adjacency $ ilde{A}$
  • Formulation: Kipf-Welling: $Z = ilde{D}^{-1/2} ilde{A} ilde{D}^{-1/2} X W$
  • Output: 32-dimensional topological embedding
Standalone $R^2 = 74.20\%$ · RMSE = 1,784.50

Hybrid CNN-LSTM-GCN Framework for Spatio-Temporal Crime Prediction

This platform presents the Hybrid CNN-LSTM-GCN Framework for Spatio-Temporal Crime Prediction, an academic deep learning research platform that integrates Convolutional Neural Networks (1D-CNN), Long Short-Term Memory (LSTM), and Graph Convolutional Networks (GCN) to jointly model localized spatial patterns, longitudinal temporal dynamics, and inter-district topological crime diffusion across Indian districts.

Project Overview

Crime prediction is a crucial challenge for law enforcement and public safety organizations. Traditional statistical models often fail to capture the multi-scale, non-linear relationships in crime data, particularly when localized crime category interactions, multi-year temporal momentum, and geographic cross-district spillover effects operate simultaneously.

Deep Learning and Graph Neural Networks offer transformative capabilities for this problem. Convolutional layers extract localized multi-dimensional crime correlations, recurrent memory cells capture sequential temporal trends, and graph convolutional networks propagate topological spillover across geographic boundary networks.

The purpose of this project is to design, implement, and evaluate a unified tri-modal hybrid deep learning framework that integrates 1D-CNN, LSTM, and GCN components to jointly model spatial distribution, temporal dynamics, and topological inter-district crime spillover relationships.

AI-Based Prediction

Leverages artificial intelligence and deep neural networks to identify non-linear spatial, temporal, and graph topological patterns in historical crime data to generate accurate forward-looking forecasts.

Tri-Modal Hybrid Deep Learning

Combines 1D-CNN (64-dim spatial), LSTM (32-dim temporal), and Spectral GCN (32-dim topological) architectures into a unified 128-dim dense representation to capture comprehensive spatio-temporal-topological crime dynamics.

Structured Historical Dataset

Utilizes a preprocessed Indian district crime dataset spanning 2001–2014 with 33 engineered predictor features and 850 indexed district nodes to train and validate all five deep learning architectures.

Capture Spatial Correlations

Extract localized multi-category crime interactions and hotspot concentrations across 33 crime types using 1D convolutional feature extractors.

Learn Temporal Dynamics

Model Spatial Topology & Spillover

Provide data-driven predictive intelligence, geographic hotspot alerts, and risk assessments to assist tactical resource allocation and preventive policing.

06

Advance Spatio-Temporal AI Research

Spatial

1D CNN Branch

Extracts localized inter-feature correlations and spatial feature combinations across 33 crime types.

  • Conv1D(64 filters, kernel=3, ReLU)
  • MaxPooling1D • BatchNormalization
  • Dense spatial embedding vector: 64 units
Temporal

LSTM Branch

Learns sequential crime trend patterns across multi-year temporal sliding windows.

  • CuDNNLSTM(64 units, return_sequences=True)
  • LSTM(32 units) • Dropout(0.2)
  • Temporal context vector: 32 units
Topology

Spectral GCN Branch

Propagates spatial crime influence across neighboring districts via normalized graph adjacency.

  • Kipf-Welling Normalization: $\tilde{D}^{-1/2}\tilde{A}\tilde{D}^{-1/2}$
  • Static $850 \times 850$ $k$-NN Adjacency Matrix
  • Graph topological embedding vector: 32 units

Research Contributions

Tri-Modal Hybrid Architecture

Design and realization of the 3-Way CNN-LSTM-GCN framework integrating spatial convolutions, recurrent memory, and spectral graph convolutions into a unified 128-dim dense embedding.

Engineered Spatial-Temporal-Graph Features

Development of 33 model-ready crime predictors combined with geographic centroid coordinates and an 850-district $k$-NN spatial graph adjacency matrix.

Longitudinal Multi-Year Trend Analysis

Comprehensive evaluation of historical crime patterns across 13+ years (2001–2014) to capture seasonal and multi-year momentum across Indian districts.

Empirical Benchmark Superiority

Demonstrated performance gains achieving 98.10% held-out test $R^2$ (and 96.10% 5-fold CV $R^2$), establishing clear superiority over standalone single-domain baselines.

Project Overview

Crime prediction has long been a critical challenge for law enforcement agencies and public safety organizations. Traditional statistical approaches often struggle to capture the complex, non-linear relationships that exist within crime data, particularly when both spatial distribution and temporal trends must be considered simultaneously.

Artificial Intelligence and Deep Learning offer powerful tools for addressing this challenge. Unlike conventional models, deep learning architectures can automatically learn hierarchical representations from raw data, making them well suited for identifying hidden spatial clusters and temporal dependencies in crime occurrences.

The purpose of this project is to design, implement, and evaluate a hybrid deep learning framework that integrates CNN and LSTM components to jointly model spatial and temporal characteristics of crime data.

AI-Based Prediction

Leverages artificial intelligence to identify patterns in historical crime data and generate forward-looking predictions.

Hybrid Deep Learning

Combines CNN and LSTM architectures into a single hybrid model to capture both spatial and temporal characteristics of crime data.

Historical Crime Dataset

Utilizes a structured historical crime dataset spanning multiple years and features to train and validate the prediction framework.

Hybrid Model Architecture

Historical Multi-Feature Crime Input (2001–2013)
Feature Engineering & Multi-View Tensor Transformation (33 Features)
Spatial Branch

1D CNN

Localized Crime Features • Shape: (Batch, 1, 33)
Temporal Branch

CuDNN LSTM

Multi-Year Sequence Memory • Shape: (Batch, 3, 33)
Graph Spatial Branch

GCN Layer

Topological Message Passing • Matrix: (850 × 850)
Multi-View Fusion Head (Concatenate → Dense 128 → Dropout 0.3)
Continuous Crime Forecast & Risk Classification (5-Fold CV R² = 96.10%)
Spatial

1D CNN Branch

Extracts localized inter-feature correlations and spatial feature combinations.

  • Conv1D(64 filters, kernel=3, ReLU)
  • MaxPooling1D • BatchNormalization
  • Dense embedding vector: 64 units
Temporal

LSTM Branch

Learns sequential crime trend patterns across multi-year temporal sliding windows.

  • CuDNNLSTM(64 units, return_sequences=True)
  • LSTM(32 units) • Dropout(0.2)
  • Temporal context vector: 32 units
Topology

GCN Branch

Propagates spatial crime influence across neighboring districts via graph adjacency.

  • Kipf-Welling Normalization: $\tilde{D}^{-1/2}\tilde{A}\tilde{D}^{-1/2}$
  • Static $850 \times 850$ $k$-NN Adjacency Matrix
  • Graph embedding vector: 32 units

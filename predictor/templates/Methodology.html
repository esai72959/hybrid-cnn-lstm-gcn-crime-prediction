Research Methodology

Hybrid CNN-LSTM-GCN Framework for Spatio-Temporal Crime Prediction

The methodology combines spatial learning through a Convolutional Neural Network (CNN) with temporal learning through a Long Short-Term Memory (LSTM) network and topological graph convolutions (GCN), allowing the framework to learn district-level spatial patterns, year-over-year temporal trends, and spatial graph adjacency before producing a crime prediction.

Dataset & Data Collection

Historical District-Level Records

The framework is trained on historical district-level crime records spanning 2001–2013. Each record contains crime-related attributes that are used for analysis and as the basis for prediction.

Source: Crimes in India Dataset 2001–2013 (Kaggle)

Feature Engineering

33 Model-Ready Features

The project prepares 33 model-ready spatial and temporal features from the preprocessed dataset. Engineered features give the CNN and LSTM branches structured signals to learn from directly, helping each branch capture spatial and temporal patterns more effectively than raw, unprocessed data would allow.

CNN Branch — Spatial Learning

The CNN branch is responsible for extracting spatial patterns from the engineered features. It learns localized crime patterns across regions and districts, identifying spatial correlations that are not easily captured by traditional methods. The output of this branch is a spatial feature representation that is passed forward for fusion with the temporal branch.

LSTM Branch — Temporal Learning

The LSTM branch models temporal dependencies within the crime data. It learns trends and relationships across historical years, capturing how crime patterns evolve over time. The output of this branch is a temporal feature representation that is passed forward for fusion with the spatial branch.

Hybrid CNN-LSTM-GCN Architecture

Spatial, temporal, and topological graph representations are learned in parallel, then fused into a unified hybrid representation before prediction.

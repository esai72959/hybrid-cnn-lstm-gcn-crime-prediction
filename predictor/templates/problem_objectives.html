Problem & Objectives

Crime is shaped by where and when it happens. This page outlines the core problem this research addresses, why existing approaches fall short, and the objectives guiding the design of the Hybrid CNN-LSTM-GCN Framework for Spatio-Temporal Crime Prediction.

Spatial Analysis Temporal Modeling Deep Learning

The Problem

Crime patterns shift across both geography and time, and most models only capture one dimension at once.

The Objective

Design a hybrid deep learning framework that learns spatial and temporal patterns jointly, improving prediction quality.

Problem Statement

Predicting crime accurately is difficult because crime data is inherently spatio-temporal, non-linear, and resistant to the assumptions traditional statistical models rely on.

Spatial & Temporal Coupling

Crime incidents are distributed unevenly across districts and evolve differently over time. Analyzing either dimension in isolation discards information the other dimension depends on.

Non-Linear Relationships

Crime is influenced by many interacting factors whose combined effect is rarely linear, making it difficult for classical statistical techniques to represent the underlying structure.

Limits of Traditional Methods

Conventional regression and time-series methods are typically built to handle either spatial distribution or temporal trends, rarely both together, which caps their predictive accuracy.

Research Need

CNNs and LSTMs each address one half of the problem. Combining them into a single framework closes the gap left by using either architecture alone.

CNN Alone

Effective at extracting spatial correlations and localized patterns, but has no built-in mechanism for modeling how those patterns change over time.

LSTM Alone

Well suited to learning sequential and temporal dependencies, but does not natively capture spatial structure across districts.

This Project

Hybrid CNN-LSTM-GCN

Combines convolutional, recurrent, and graph architectures so spatial, temporal, and topological graph representations are learned jointly.

Project Objectives

01

Improve Prediction Accuracy

Enhance the accuracy of crime forecasting through a hybrid deep learning approach.

02

Capture Spatial Patterns

Identify spatial correlations and hotspot regions using convolutional feature extraction.

03

Learn Temporal Dependencies

Model sequential and time-based crime trends using LSTM-based temporal learning.

04

Analyze Historical Trends

Provide meaningful analysis of historical crime patterns across districts and years.

05

Generate Future Predictions

Produce forward-looking crime predictions to support planning and research use cases.

06

Support Data-Driven Research

Provide a research-oriented platform for exploring crime prediction and model results.

Expected Outcome

What this research is intended to deliver by the end of the project.

Hybrid CNN-LSTM-GCN Framework

A working framework that jointly learns spatial, temporal, and graph topological crime patterns.

District-Level Prediction

Crime predictions generated at the district level for practical relevance.

Historical Trend Analysis

Clear analysis of how crime patterns have shifted across years and regions.

Future Forecasting

Forward-looking estimates that extend beyond the historical dataset.

Model Comparison

Benchmarking the hybrid model against standalone CNN and LSTM baselines.
